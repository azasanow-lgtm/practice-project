# Мой первый проект

Практическая работа по системе контроля версий Git.

Проект создан в рамках учебной практики.

## Установка

1. Клонируйте репозиторий:
   git clone https://github.com/ТВОЙ_ЛОГИН/practice-project.git

2. Перейдите в папку проекта:
   cd practice-project

## Использование

Откройте файл `index.html` в браузере для просмотра проекта.
